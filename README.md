# SimulCost

**A Cost-Aware Benchmark for Automating Physics Simulations with LLMs**

This repository contains the project website for SimulCost, hosted via GitHub Pages.

## Development

```bash
npm install
npm run dev       # Start dev server at localhost:4321
npm run build     # Build for production
npm run preview   # Preview production build
```

Website content is configured in `src/content/site.config.ts`.
